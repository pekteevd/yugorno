# Изображения Югорно

Визуальные слоты исходного прототипа сохранены. Семантические ключи находятся в
`public/assets/images.json`:

- `hero`
- `trip-karelia`
- `trip-u-ilem`
- `trip-teriberka`
- `community-u-ilem`
- `community-road`
- `community-trails`

Сейчас используются прежние URL изображений исходного HTML-прототипа. Они
восстановлены в `images.json` и продублированы как CSS-значения по умолчанию,
чтобы отказ загрузки каталога не стирал исходные привязки.

Позже, когда пользователь выберет фотографии, их можно будет положить в
`public/assets/images/` и заменить значения ключей на локальные пути, например:
`/assets/images/teriberka-cover.webp`.

HTML, карточки и логика разделов при такой замене не меняются. Не использовать
новые временные иллюстрации вместо исходных фотографий без согласования.
